1. HTML basics

HTML means HyperText Markup Language. It describes the structure and meaning of web content. A browser reads HTML and presents its elements as a web page.

Tag
The markup written between angle brackets, such as <p> or </p>.
Element
The complete structure: usually an opening tag, content, and a closing tag. For example, <p>Hello</p>.
Attribute
Extra information written in an element's opening tag, such as href in <a href="page.html">.
Content
The text or other elements placed between an element's opening and closing tags.

Most elements have an opening and closing tag. Void elements have no closing tag and cannot contain content. Examples include <img>, <br>, and <input>. In HTML, the slash in <img /> is optional.

Element names are generally written in lowercase. Nest elements in the correct order: close the most recently opened element first.

<p>This is <strong>important</strong> text.</p>

2. Document structure

<!DOCTYPE html>
Declares an HTML document and asks browsers to use standards mode. It is a declaration, not an HTML element.
<html>
The root element containing the entire page. The lang attribute identifies the page's language.
<head>
Contains document information and resource references that are not the main page content.
<title>
Sets the document title, commonly shown in the browser tab and used by bookmarks and search results.
<meta>
Provides metadata, such as character encoding, a description, or a responsive viewport setting.
<link>
Links the document to an external resource, often a website icon or a stylesheet.
<body>
Contains the content displayed as part of the page.

A minimal document begins with the doctype, followed by html, head, and body. This page uses that structure.

3. Text elements

<h1> through <h6>
Headings arranged by importance and level. Use them in a logical hierarchy; do not choose a heading only for its default appearance.
<p>
A paragraph of text.
<br>
A line break within text, such as in an address or poem. It is a void element.
<hr>
A thematic break between paragraphs or sections. It is a void element.
<strong>
Marks content as strongly important.
<em>
Marks stress emphasis.
<b>
Draws attention to text without adding importance or emphasis.
<i>
Marks text set apart from ordinary prose, such as a technical term or a phrase in another language.
<u>
Marks text with a non-textual annotation. Do not use it just to imitate a link.
<s>
Marks text that is no longer accurate or relevant.
<small>
Marks side comments or small print.
<mark>
Marks text as relevant to the current context.
<sub> and <sup>
Mark subscript and superscript text.
<code>
Marks a short fragment of computer code.
<pre>
Represents preformatted text, preserving spaces and line breaks.
<kbd>, <samp>, and <var>
Represent user input, program output, and a variable, respectively.
<q> and <blockquote>
Represent a short inline quotation and a longer quoted section.
<cite>
Identifies the title of a creative work or other cited source.
<abbr>
Marks an abbreviation. Its optional title attribute can provide the expanded form.
<time>
Marks a date or time. The optional datetime attribute supplies a machine-readable value.
<data>
Connects visible content with a machine-readable value using its value attribute.
<del> and <ins>
Mark deleted and inserted content. They can use cite and datetime attributes.
<bdi> and <bdo>
Isolate text with a different writing direction, or explicitly set a text direction with dir.
<span>
A generic inline container with no meaning of its own.
<wbr>
Suggests a possible line-break position in a long word or string.
<ruby>, <rt>, and <rp>
Represent ruby annotations, often pronunciation guides for East Asian text, including fallback parentheses.

4. Grouping and lists

<div>
A generic block container with no meaning of its own.
<ul>
An unordered list, usually shown with bullets.
<ol>
An ordered list. Attributes include start, reversed, and type.
<li>
A list item inside an ordered or unordered list.
<dl>
A description list for terms and their descriptions or other name-value groups.
<dt> and <dd>
A term or name and its description or value in a description list.
<figure> and <figcaption>
Group self-contained content, such as an illustration, with an optional caption.

5. Links and embedded content

<a>
Creates a hyperlink. Common attributes include href, target, rel, download, and hreflang.
<img>
Embeds an image. Use src for its address and a meaningful alt description when the image conveys information. It is a void element.
<picture> and <source>
Offer different media sources or image formats. A source can use srcset, sizes, media, and type.
<audio> and <video>
Embed sound and video. Common attributes include controls, src, autoplay, loop, and muted. Prefer providing controls and captions where appropriate.
<track>
Provides timed text such as subtitles for audio or video. Common attributes include kind, src, srclang, and label.
<iframe>
Embeds another page. Important attributes include src, title, width, height, loading, and sandbox.
<embed> and <object>
Embed external resources. Their use depends on the resource and browser support.
<param>
Historically supplied parameters to an object; it is obsolete and should not be used in new pages.
<map> and <area>
Define clickable regions on an image. area uses attributes such as shape, coords, and href.
<canvas>
Provides a drawable bitmap area, typically controlled with JavaScript. Without JavaScript, include fallback content inside it.
<svg>
Embeds scalable vector graphics markup in a page.
<math>
Embeds MathML mathematical notation where supported.

6. Tables

Use a table for data arranged in rows and columns, not to lay out a page.

<table>
Contains tabular data.
<caption>
Provides a title or explanation for a table.
<thead>, <tbody>, and <tfoot>
Group the header, main body, and footer rows.
<tr>
A table row.
<th>
A header cell. The scope attribute can identify whether it labels a row or column.
<td>
A data cell. colspan and rowspan can make a cell span columns or rows.
<colgroup> and <col>
Identify groups of table columns.

7. Forms

Forms collect information from users. A form usually needs a server or JavaScript to process its data.

<form>
Groups controls for submission. Common attributes include action, method, enctype, and autocomplete.
<label>
Names a form control. Connect it to a control using a matching for and id.
<input>
A void form control. Its type selects a kind of input, such as text, email, password, number, date, checkbox, radio, file, or submit.
<textarea>
A multi-line text input. Common attributes include rows, cols, name, and maxlength.
<button>
A button. Set type to submit, reset, or button to make its purpose clear.
<select>, <option>, and <optgroup>
Create a choice menu, its choices, and labeled groups of choices.
<datalist>
Provides suggested options for an input whose list attribute refers to its id.
<fieldset> and <legend>
Group related form controls and provide a caption for the group.
<output>
Represents the result of a calculation or user action.
<progress>
Shows the completion progress of a task. It can use value and max.
<meter>
Shows a measurement within a known range, using attributes such as min, max, and value.

Frequently used form attributes include name (submitted field name), value (current or default value), placeholder (a hint, not a replacement for a label), required, disabled, readonly, min, max, step, minlength, maxlength, pattern, and autocomplete.

8. Semantic page sections

Semantic elements describe the role of their content. They help browsers, search systems, and assistive technology understand a page.

<header>
Introductory content for a page or section.
<nav>
A section containing important navigation links.
<main>
The dominant content of the page. A page should generally have one visible main content area.
<section>
A thematic group of content, usually with a heading.
<article>
Self-contained content that could make sense on its own, such as a post or news story.
<aside>
Related or supplementary content.
<footer>
Footer information for a page or section.
<address>
Contact information for the nearest article or page.

9. Interactive and scripting elements

<details> and <summary>
Create a disclosure widget that the user can open and close. summary is its visible heading.
<dialog>
Represents a dialog box. Opening and managing it generally requires JavaScript.
<script>
Embeds or refers to JavaScript. It is intentionally not used to add behavior in this HTML-only guide.
<noscript>
Provides fallback content when scripting is unavailable or disabled.
<template>
Holds HTML that is not displayed until code uses it.
<slot>
Marks a placeholder in a web component's shadow tree.

10. Attributes

Attributes appear in an element's opening tag as a name and, usually, a value: <a href="https://example.com">Example</a>. Quote attribute values. Some attributes are Boolean: their presence means true, and their absence means false. For example, <input required>.

Common global attributes

Global attributes can be used on many HTML elements, subject to each element's rules.

id
A unique identifier in the document; useful for links, labels, and scripts.
class
A space-separated set of names for identifying or grouping elements.
title
Advisory text about an element. Do not rely on it as the only way to communicate important information.
lang
The language of the element's content, commonly set on html.
dir
The text direction: ltr, rtl, or auto.
hidden
Indicates that the element is not currently relevant and should not be presented.
tabindex
Controls keyboard focus behavior. Use carefully and preserve a logical tab order.
contenteditable
Indicates whether the user can edit an element's content.
draggable
Indicates whether an element can be dragged; behavior commonly requires scripting.
spellcheck
Hints whether spelling and grammar may be checked.
translate
Hints whether an element's text should be translated.
autocapitalize
Hints how text entry may capitalize input on supporting devices.
accesskey
Suggests a keyboard shortcut. Shortcuts can conflict with browser or assistive-technology commands.
data-*
Custom data attributes, such as data-category="books", for page-specific data.
role and aria-*
Accessibility attributes that can describe roles and properties. Prefer native semantic HTML and use ARIA only when needed.
style
An attribute for inline CSS. It is mentioned for completeness but is not used here because this guide is HTML-only.
on* event attributes
Attributes such as onclick can run JavaScript. They are not used in this HTML-only guide; keep behavior in separate, maintainable code when scripting is needed.

Frequently used element-specific attributes

Links: href, target, rel, download
Set a destination, browsing context, relationship, or download behavior on a link.
Images: src, alt, width, height, loading
Set an image source, text alternative, dimensions, or loading hint.
Media: src, controls, autoplay, loop, muted, poster
Set media source and playback options; poster specifies a preview image for video.
Forms: action, method, name, type, value, required
Set form submission behavior and identify or configure controls.
Tables: scope, colspan, rowspan
Describe header coverage or let a cell span columns or rows.
Metadata: charset, name, content
Describe document metadata, such as character encoding or a page description.
Resources: rel, href, media, type
Describe a linked resource and its intended use.

Character references

Write reserved characters using character references when they would otherwise be interpreted as markup. For example, &lt; displays <, &gt; displays >, and &amp; displays &. Quotes in attribute values can be written as &quot;.

11. Obsolete elements

Some old HTML tags are obsolete or nonconforming and should not be used in new work. Examples include <font>, <center>, <marquee>, <big>, <strike>, and <frameset>. Use meaningful HTML for structure and a stylesheet when visual styling is needed.

HTML evolves over time. This guide introduces the main standard elements and common attributes; it is not an exhaustive specification of every attribute combination or browser feature.
